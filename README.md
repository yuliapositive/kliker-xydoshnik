# 🎨 Кликер-Художник

**Пиксель-арт игра, где ты повторяешь эталонные рисунки по клеточкам.**

![Демо игры](https://yuliapositive.github.io/kliker-xydoshnik/)

## 🎯 Суть игры

- Выбери эталон (сердце, цветок, заяц, щенок, кот или свободный режим)
- Закрашивай клетки на поле, повторяя рисунок
- Нажми «Проверить» — игра покажет % совпадения
- Бей свои рекорды! Лучший результат сохраняется в браузере

## ✨ Особенности

- 🎨 **5 цветов** в палитре
- 🎲 **Генератор случайных фигур** (квадраты, круги, треугольники и др.)
- 📱 **Адаптив** — играет на телефонах и планшетах
- 🏆 **Рекорды** — сохраняются в localStorage
- 👆 **Интуитивное управление** — клик закрашивает, повторный клик стирает

## 🕹️ Как играть

1. Выбери эталон сверху
2. Выбери цвет в палитре
3. Кликай по полю слева, чтобы закрашивать клетки
4. Нажми «Проверить», чтобы узнать результат
5. Старайся достичь 100% совпадения!
